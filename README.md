# 习惯打卡

一个简单的每日习惯打卡网页。添加自己想坚持的习惯，每天完成一项就点一下打勾。

## 直接使用

打开下面的网址就能用，不需要注册，不需要安装：

https://hufangjie999-design.github.io/habit-check-in/

## 功能

- 自己添加习惯，比如喝水、运动、读书
- 每天点一下打勾，完成的习惯会变灰
- 页面顶部显示今天一共完成了几项
- 鼠标移到习惯上会出现 × 按钮，可以删除

## 数据存在哪

打卡记录保存在你自己浏览器的本地存储里，只属于你本人，别人看不到。换一台设备或者换一个浏览器，记录不会同步过去。

## 想自己部署一份

1. 点页面右上角的 `Fork`，把它复制到你的账号下
2. 打开你仓库的 `Settings` → `Pages`
3. 把 `Branch` 设为 `main`，保存
4. 等一两分钟后，访问 `https://你的用户名.github.io/habit-check-in/`
